### 1. En chat_luma.py, Luma quiere que el asistente recuerde el turno anterior en una conversación de consola. ¿Qué línea permite encadenar el contexto entre solicitudes?

- ❌ **A.** Guardar `deployment = os.environ["MODEL_DEPLOYMENT_NAME"]` antes del bucle.  
  Eso solo selecciona el deployment que responderá; no conserva estado de conversación.
- ✅ **B.** Enviar `previous_response_id=previous_id` y luego asignar `previous_id = response.id`.  
  Ese valor enlaza la nueva respuesta con la anterior para mantener continuidad.
- ❌ **C.** Usar `DefaultAzureCredential()` al crear `AIProjectClient`.  
  La credencial autentica al usuario o aplicación; no administra memoria conversacional.
- ❌ **D.** Cambiar `instructions` en cada vuelta del bucle.  
  Modificar instrucciones puede cambiar conducta, pero no encadena el historial.

**Respuesta:** B. El cliente conserva contexto pasando el id de la respuesta previa y actualizándolo con cada respuesta nueva. Sin ese enlace, cada llamada se trata como una interacción aislada. Repasa las lecciones 17 y 18.

### 2. Un gerente pide ocultar que el chat de Luma usa IA para que los clientes “confíen más”. ¿Qué principio queda más comprometido?

- ❌ **A.** Fairness, porque el asistente podría tratar de forma distinta a distintos clientes.  
  Fairness trata el trato equitativo; aquí el riesgo principal es no revelar cómo funciona el sistema.
- ✅ **B.** Transparency, porque el usuario debe saber que interactúa con un sistema de IA.  
  La transparencia exige explicar capacidades, límites y uso de IA cuando afecta al usuario.
- ❌ **C.** Reliability and Safety, porque el modelo podría responder con errores.  
  La seguridad importa, pero el escenario se centra en ocultar la naturaleza del asistente.
- ❌ **D.** Inclusiveness, porque algunos clientes podrían no usar chat.  
  Inclusiveness busca acceso para distintas personas; no es el problema central descrito.

**Respuesta:** B. Responsible AI no solo evita daños técnicos; también exige claridad con las personas afectadas. Si el usuario no sabe que habla con IA, no puede calibrar la respuesta ni pedir escalamiento. Repasa las lecciones 7 y 8.

*Objetivo: Describe principles of responsible AI · Lecciones: 7, 8*

### 3. Luma quiere analizar tickets y guardar resultados consistentes en su CRM: idioma, PII redactada y categoría. ¿Qué acciones son adecuadas? Selecciona DOS respuestas.

- ✅ **A.** Usar Azure Language para detectar idioma y PII cuando se requieran capacidades predefinidas.  
  Azure Language ofrece capacidades específicas como idioma y PII con salidas estructuradas.
- ✅ **B.** Pedir a un modelo general que responda con JSON y validar el JSON antes de guardarlo.  
  Un modelo general puede hacer análisis flexible, pero la aplicación debe validar el formato.
- ❌ **C.** Confiar en que un confidence score de 0.91 garantiza que la categoría es verdadera.  
  El confidence score indica confianza del servicio, no una garantía absoluta de verdad.
- ❌ **D.** Enviar el ticket directamente a text-to-speech para obtener sentimiento.  
  Text-to-speech genera audio desde texto; no detecta sentimiento ni PII.
- ❌ **E.** Eliminar la revisión humana de todos los casos con entidades personales.  
  La PII y casos sensibles suelen requerir controles y revisión, no menos supervisión.

**Respuesta:** A, B. El curso muestra dos enfoques: modelos generales con salida estructurada y Azure Language para capacidades específicas. En ambos casos debes validar resultados antes de integrarlos. Repasa las lecciones 26, 27, 28 y 29.

*Objetivo: Build a lightweight application that includes text analysis · Lecciones: 26, 27, 28, 29*

### 4. Una aseguradora debe procesar prompts solo dentro de la Unión Europea y pagar por token, sin reservar capacidad. ¿Qué deployment type encaja mejor?

- ❌ **A.** Global Standard  
  Global Standard puede procesar en cualquier región de Azure, por lo que no satisface residencia por zona.
- ❌ **B.** Provisioned regional  
  Provisioned reserva capacidad y no cumple la condición de pagar solo por token.
- ✅ **C.** Data Zone Standard  
  Data Zone Standard procesa dentro de una zona como EU y se paga por token.
- ❌ **D.** Global Batch  
  Global Batch es para trabajos asíncronos grandes y procesa globalmente, por lo que no satisface residencia EU.

**Respuesta:** C. La pista es residencia de datos por zona más pago por token. Data Zone Standard se diseñó para ese requisito, a diferencia de Global Standard o Provisioned. Repasa las lecciones 11 y 13.

*Objetivo: Identify appropriate model deployment options and configuration parameters · Lecciones: 11, 13*

### 5. El equipo de soporte quiere una solución que converse con clientes, consulte políticas y decida cuándo escalar a un humano. ¿Qué workload describe mejor la solución?

- ❌ **B.** Computer vision  
  Computer vision interpreta imágenes; el escenario se centra en conversación y herramientas.
- ✅ **C.** Agentic AI sobre un modelo generativo  
  Un agente combina modelo generativo, instrucciones y tools para cumplir un objetivo.
- ❌ **D.** Machine Learning de regresión  
  La regresión predice valores numéricos y no cubre la interacción descrita.

**Respuesta:** C. Un agente no es un modelo nuevo: es una aplicación que usa un modelo generativo, instrucciones y herramientas. Esa combinación permite consultar conocimiento, actuar y escalar. Repasa las lecciones 4, 5 y 20.

### 6. Un prompt de Luma devuelve respuestas largas y a veces promete reembolsos. ¿Qué cambio es el más adecuado en el system prompt?

- ❌ **A.** Pedir “sé amable” y dejar que el modelo decida los límites.  
  Es demasiado vago y no fija políticas ni formato de respuesta.
- ✅ **B.** Incluir rol, límites: no prometer reembolsos, tono, idioma y cuándo escalar.  
  Un buen system prompt define rol, reglas, límites, tono y criterios de escalamiento.
- ❌ **C.** Quitar el system prompt y poner toda la política en el user prompt.  
  El user prompt cambia por turno; las instrucciones base deben quedar en el system prompt.
- ❌ **D.** Subir la temperatura para que el modelo sea más creativo.  
  Más creatividad puede aumentar variación; no corrige límites de política.

**Respuesta:** B. Los prompts efectivos especifican contexto, tarea, restricciones y formato. Para políticas de soporte, el system prompt debe fijar límites que el usuario no pueda sobrescribir fácilmente. Repasa las lecciones 14, 15 y 16.

*Objetivo: Create effective system and user prompts for generative AI models · Lecciones: 14, 15, 16*

### 7. Luma planea guardar grabaciones de voz completas de clientes sin aviso para mejorar transcripciones futuras. ¿Qué principio debes priorizar?

- ❌ **A.** Accountability  
  Accountability define responsables, pero el riesgo principal es privacidad de los datos de voz.
- ❌ **B.** Inclusiveness  
  Inclusiveness busca accesibilidad; no trata principalmente almacenamiento sin aviso.
- ✅ **C.** Privacy and Security  
  La voz es dato personal; se requiere protegerla, avisar y limitar su uso.
- ❌ **D.** Fairness  
  Fairness se centra en trato equitativo entre grupos, no en consentimiento y protección de datos.

**Respuesta:** C. Los datos personales, como voz, identificadores y facturas, requieren controles de privacidad y seguridad. El curso también conecta speech con consentimiento y uso responsable. Repasa las lecciones 7 y 8.

### 8. Un alumno dice: “El LLM sabe la respuesta porque busca en una base de datos interna en cada token”. ¿Cuál es la corrección más precisa?

- ❌ **A.** Un LLM siempre ejecuta código para calcular la respuesta exacta.  
  Puede integrarse con tools, pero no ejecuta código por defecto en cada respuesta.
- ❌ **B.** Un LLM solo copia frases completas de los datos de entrenamiento.  
  Genera nuevo texto combinando patrones; no es un mecanismo de copia literal.
- ❌ **C.** Un LLM convierte todo prompt en una imagen latente antes de responder.  
  Eso no describe el funcionamiento de modelos de lenguaje vistos en el curso.
- ✅ **D.** Un LLM predice tokens usando patrones aprendidos; puede usar contexto o tools si la aplicación los proporciona.  
  El modelo genera tokens a partir de patrones y contexto; no consulta automáticamente una base externa.

**Respuesta:** D. Generative AI produce contenido prediciendo tokens condicionados por el prompt, instrucciones y contexto. Por eso validas resultados y usas tools o grounding cuando necesitas datos específicos. Repasa las lecciones 6 y 19.

*Objetivo: Describe how generative AI models work · Lecciones: 6, 19*
